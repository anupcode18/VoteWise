# PROJECT: ElectEase AI

## OVERVIEW
ElectEase AI is a context-aware civic guidance assistant designed to help users understand and navigate election processes in an interactive, step-by-step manner. This is a structured decision-making assistant, not a chatbot.

## GOAL
Create a smart, secure, and scalable assistant that demonstrates logical decision-making, context awareness, reliable outputs, and real-world usability.

## TECH STACK
- **Frontend**: HTML, CSS, Vanilla JavaScript
- **Core Logic**: JavaScript Decision Engine (rule-based)
- **AI Layer**: Google Antigravity (GSD protocol)
- **Data**: Static JSON (predefined election flows)

## ARCHITECTURE
User -> UI -> Decision Engine -> Antigravity (GSD) -> Verified Output -> User

## CONSTRAINTS
- Repository size < 1 MB
- Minimal dependencies
- Security-first (input/output validation)
- Deterministic outputs
